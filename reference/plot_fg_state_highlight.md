# generate a plot of just the foreground states, making the background white.

These are the actual state values of the bins in foreground events.

## Usage

``` r
plot_fg_state_highlight(states_df, phylogeny, file_name)
```

## Arguments

- states_df:

  bin based dataframe that has foreground events marked.

- phylogeny:

  phylo object used to infer foreground

- file_name:

  name for the resulting png.
