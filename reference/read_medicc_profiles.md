# ingest a medicc profiles file

This file is part of the standard medicc output files and contains all
of the input data and their states, plus the medicc generated state
profiles of the internal tree nodes.

## Usage

``` r
read_medicc_profiles(meddic_profiles_file)
```

## Arguments

- meddic_profiles_file:

  file path

## Value

tibble of file contents

## Details

Applies changes that are needed for other functions.
