# generate a plot of just the background states, making the foreground white.

These are the actual state values of the bins in background bins.

## Usage

``` r
plot_bg_state_highlight(states_df, phylogeny, file_name)
```

## Arguments

- states_df:

  bin based dataframe that has foreground events marked.

- phylogeny:

  phylo object used to infer foreground

- file_name:

  name for the resulting png.
