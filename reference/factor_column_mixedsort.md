# naturally sort a column from a dataframe.

Common plotting issue, used mixed sort so things like, e.g., chromosomes
get sorted properly chr1, chr2, ..., chr10

## Usage

``` r
factor_column_mixedsort(df, col)
```

## Arguments

- df:

  a dataframe that contains the column to sort

- col:

  the column to sort

## Value

factor of the column with sorted levels
