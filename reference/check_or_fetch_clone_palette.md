# confirm pallete given has enough colors or generate one

confirm pallete given has enough colors or generate one

## Usage

``` r
check_or_fetch_clone_palette(clones_df, clone_palette = NULL)
```

## Arguments

- clones_df:

  dataframe with a column of clone_id and the cells assigned to each
  (long format)

- clone_palette:

  named vector of how to color the clones.
